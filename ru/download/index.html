Вопросы о скачивании и установке

GlotChat можно скачать бесплатно?

Да. Скачивание бесплатное, а 3-дневный период открывает все функции без оплаты. После него тарифы — от 69 USDT в год.

Почему Windows пишет «Система Windows защитила ваш компьютер»?

Windows SmartScreen показывает это для новых приложений, которые ещё редко видел. Нажмите Подробнее, затем Выполнить в любом случае. Скачивайте GlotChat только с этой страницы — сверьте SHA-256, чтобы убедиться, что файл оригинальный.

Почему версия установщика старше последней версии GlotChat?

Установщик остаётся на версии, которой Windows уже доверяет, чтобы он без проблем ставился на любой ПК. Через минуту после запуска GlotChat сам обновится до последней версии (с Telegram и всеми новинками).

Нужен ли ключ лицензии?

Для бесплатного периода — нет: нажмите Начать бесплатный период на 3 дня в программе. Купив тариф, вы получите годовой ключ в Telegram — вставьте его в У меня уже есть ключ.

Есть версия для Mac, Android или iPhone?

Пока нет. GlotChat — программа для Windows 10 и 11. Аккаунты остаются на телефонах — GlotChat подключает их к ПК, как WhatsApp Web.

Как удалить GlotChat?

Откройте Параметры → Приложения → Установленные приложения в Windows, найдите GlotChat и нажмите Удалить.

Загрузка остановилась или идёт медленно. Что делать?

Нажмите кнопку загрузки ещё раз. Если не помогло, напишите нам в Telegram — пришлём установщик напрямую.
