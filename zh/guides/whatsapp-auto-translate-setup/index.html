做外贸、跨境电商或者接待海外客户，最费时间的往往不是谈生意，而是来回复制粘贴翻译：把客户的消息复制到翻译网站，再把译文粘回 WhatsApp。客户一多、号码一多，根本忙不过来。

简短回答：WhatsApp 本身没有自动翻译功能。在电脑上用 GlotChat 打开你的 WhatsApp 账号，收到的消息会自动在原文下方显示中文翻译；你用中文输入，按回车前就能看到译文，确认后发出。

第 1 步：安装 GlotChat，开始免费试用

下载 GlotChat Windows 版（支持 Windows 10 / 11），安装后打开，点击 “开始 3 天免费试用”。试用包含全部功能，无需付款、无需银行卡。

第 2 步：添加 WhatsApp 账号

点击 “添加账号”：

  • 名称：比如“店铺 1”“中东客户”“业务员小王”。
  • 我使用的语言：选 中文。
  • 客户使用的语言：选 “自动检测（推荐）”——每个聊天会自动识别客户说的语言。

然后点击 “添加并连接 WhatsApp”。

第 3 步：用手机扫码关联

屏幕上会出现 WhatsApp 的二维码。在手机上打开 WhatsApp：

  • 安卓：右上角 ⋮ → 已关联设备 → 关联新设备
  • iPhone：设置 → 已关联设备 → 关联新设备

扫码后，这个号码就在电脑上运行了，之后手机不用一直开着。有多个号码就重复第 2、3 步，每个号码都在自己独立的空间里，互不影响。

第 4 步：下载语言包（只需一次）

打开 “语言” 页面。界面是中文时，GlotChat 会提示 “请先下载中文”——先下载中文，再下载你的客户常用的语言，比如阿拉伯语、西班牙语、俄语、葡萄牙语。英语已内置。

每个语言包约 100–150 MB，下载一次后完全离线翻译：聊天内容不会发送到任何翻译网站，客户资料更安全。已下载的任意两种语言之间都能互相翻译。

第 5 步：收到的消息自动翻成中文

打开任意聊天，客户的每条消息下方都会自动出现中文翻译，并标注原来的语言（例如 🌐 AR）。往上翻看历史消息也一样。某条消息没有自动翻译时，点它下方的 “🌐 翻译” 即可。

第 6 步：用中文回复，客户收到他的语言

像平时一样在输入框里写中文，按回车。GlotChat 有三种发送方式（在 账号设置 → 发送 中切换，聊天窗口上方也能一键切换）：

发送方式 效果 适合
预览 先显示译文，你确认或修改后再发送 刚开始用、重要报价
即时 自动翻译并直接发送 熟练后、聊天量大
关闭 按你写的原文发送 和说中文的客户聊天

客户只会收到他自己语言的消息。需要的话，还可以设置“同时发送原文”。

语音和图片也能翻译

  • 语音消息：点击语音下方的 “🎤 转文字”，先转成文字再翻译成中文。客户发来的西班牙语、阿拉伯语语音，一眼看懂。
  • 图片中的文字：价格表、截图、单据，点击 “🔤 识别文字”，识别图片里的文字并翻译。

语音和图片同样在你的电脑上离线处理，不会上传。

提高效率的 3 个小技巧

  • 快捷回复：在输入框输入 “/” 调出常用回复（报价、发货时间、付款方式），同样会自动翻译成客户的语言。
  • 给客户固定语言：如果自动识别不准（比如很短的消息），点击聊天上方的语言按钮，给这个客户固定一种语言。
  • 多个号码一个窗口：所有号码在左侧列表，Ctrl+1…9 快速切换，每个号码的通知都标明是哪个账号。

WhatsApp 自动翻译常见问题

WhatsApp 自带自动翻译吗？

目前 WhatsApp 没有内置的聊天自动翻译。在电脑上可以用 GlotChat 这样的软件，收到的消息自动显示译文，发出的消息自动翻译成客户的语言。

翻译需要联网吗？会泄露聊天内容吗？

语言包下载一次后，翻译完全在你的电脑上离线完成，聊天、语音和图片都不会发送到任何翻译服务。WhatsApp 本身收发消息仍然需要联网。

支持哪些语言？

GlotChat 支持 49 种翻译语言，包括中文、英语、阿拉伯语、西班牙语、俄语、葡萄牙语、法语、土耳其语、越南语、泰语、印尼语等。

不知道客户说什么语言怎么办？

把“客户使用的语言”设为“自动检测（推荐）”，GlotChat 会识别每个聊天的语言，并用这个语言发送你的回复。
