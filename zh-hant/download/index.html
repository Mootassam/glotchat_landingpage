下載和安裝問題

GlotChat 可以免費下載嗎？

可以。下載免費，3 天試用期內全部功能可用，無需付款。試用結束後，套餐每年 69 USDT 起。

為什麼 Windows 提示「Windows 已保護你的電腦」？

Windows SmartScreen 對還不常見的新軟體都會顯示這個提示。點選其他資訊，再點選仍要執行。請只從本頁面下載 GlotChat —— 可以對比 SHA-256 校驗值，確認是原始檔案。

為什麼安裝包的版本比最新版舊？

安裝包保持在 Windows 已經信任的版本，這樣在任何電腦上都能順利安裝。開啟 GlotChat 一分鐘後，它會自動更新到最新版本（包括 Telegram 和所有新功能）。

需要授權碼嗎？

試用不需要：在軟體中點選開始 3 天免費試用即可。購買套餐後，我們會在 Telegram 上發給你一年的授權碼 —— 貼上到我已有授權碼中。

有 Mac、Android 或 iPhone 版嗎？

目前沒有。GlotChat 是 Windows 10 和 11 電腦軟體。你的帳號仍在手機上 —— GlotChat 像 WhatsApp 網頁版一樣把它們連結到電腦。

怎麼解除安裝 GlotChat？

開啟 Windows 設定 → 應用 → 已安裝的應用，找到 GlotChat，點選解除安裝。

下載中斷或很慢怎麼辦？

再點一次下載按鈕。如果還不行，在 Telegram 上聯絡我們，我們直接把安裝包發給你。
