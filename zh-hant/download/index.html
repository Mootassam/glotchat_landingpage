關於下載和安裝

GlotChat 可以免費下載嗎？

可以。下載免費，3 天試用期內所有功能全部開放，無需付款。試用結束後，套餐每年 69 USDT 起。

為什麼 Windows 提示「Windows 已保護你的電腦」？

Windows SmartScreen 會對還不常見的新軟體顯示這個提示。點選「其他資訊」，再點選「仍要執行」即可。請始終從本頁下載 GlotChat — 您可以核對 SHA-256 校驗值，確認檔案是原版。

需要啟用碼嗎？

試用不需要。在軟體裡點選「開始 3 天免費試用」即可立即開始。購買套餐後，我們會在 Telegram 上傳送一年期啟用碼 — 貼上到「我已經有啟用碼」中即可。

有 Mac、Android 或 iPhone 版本嗎？

目前沒有。GlotChat 是 Windows 10 和 11 電腦軟體。您的 WhatsApp 號碼仍然在手機上 — GlotChat 像 WhatsApp Web 一樣把它們連結到電腦。

Windows 7 或 8 能用嗎？

不能。GlotChat 需要 64 位的 Windows 10 或 Windows 11。

如何更新 GlotChat？

不需要手動更新。GlotChat 會自動檢查新版本，在後台下載，並在下次啟動時自動安裝。

如何解除安裝 GlotChat？

開啟 Windows「設定 → 應用 → 已安裝的應用」，找到 GlotChat，點選「解除安裝」。

下載中斷或很慢怎麼辦？

請再次點選下載按鈕。如果仍然不行，請在 Telegram 上聯絡我們，我們直接把安裝檔案發給您。
