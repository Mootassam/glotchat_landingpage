FAQ

Real estate questions

Can each agent keep their own WhatsApp number?

Yes. Each number is a separate, isolated account in GlotChat. Name them by agent or by project, and notifications always show which one a message is for.

Which languages do our buyers' messages get translated from?

49 languages for text — including Russian, Arabic, Chinese, Hindi, Persian, French, German and Turkish — and about 100 for voice notes.

Can several agents use it on different computers?

Business covers up to 3 computers. For a bigger team, ask us for a custom offer.
